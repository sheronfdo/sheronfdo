## 🚀 Featured Projects

- **[Distributed Online Auction Management System](https://github.com/sheronfdo/Auction-Management-System)**  
    A Java EE platform supporting 2000+ concurrent users with <1% error rate. Built with **EJB, JMS, Hibernate, CDI, WebSocket** on **Payara Server 6** and **PostgreSQL**, validated via **JMeter**. Features live bidding and role-based access.
    
- **[Traffic Management System](https://github.com/sheronfdo/TrafficManagementSystem)**  
    A Java EE solution optimizing urban traffic with IoT simulation, using **EJB, Servlets, Hibernate, MySQL**, and **RabbitMQ**. Includes a **Java SE** IoT simulator for scalable testing.  
    [IoT Device Simulator](https://github.com/sheronfdo/TrafficManagementSystemlotDeviceSimulator)
    
- **[Transportation Logistic Management System](https://github.com/sheronfdo/transportation_logistic_management_system)**  
    A Java EE system for inventory and shipment tracking, with **EJB, JTA, JPA, MySQL**, and **@RolesAllowed** security. Achieved 10% efficiency via GPS route optimization.
    
- **[Book4Me: Multi-Vendor Book Marketplace](https://github.com/sheronfdo/Book4Me)**  
    A MERN stack platform (React, Node.js, MongoDB, Firebase) for book trading, with **Google Sign-In**, **PayPal**, and **Firebase Cloud Messaging** supporting 10,000+ listings.
